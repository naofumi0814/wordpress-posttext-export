# WordPress PostText Export

投稿本文を中心に、必要な項目だけを選択してテキストまたはPDFでエクスポートできるWordPressプラグインです。

## 機能概要

- 投稿・固定ページ・カスタム投稿タイプの本文をエクスポート
- 出力項目を個別にチェックボックスで選択可能
- HTMLタグを除去したプレーンテキスト出力（デフォルト）
- HTML付き本文の出力にも対応
- テキスト整形オプション（段落改行、空行整理、見出し処理等）
- 投稿ステータス・期間・キーワード・ID指定による絞り込み
- TXT / PDF の2形式に対応
- 記事間の区切り設定（空行・区切り線・カスタム文字列）
- 各項目へのラベル付き／なし切り替え
- 対象件数のプレビュー表示
- UTF-8 BOM付きTXTで文字化け防止

## インストール手順

1. このリポジトリをZIPでダウンロード、または `git clone` する
2. `wordpress-posttext-export` フォルダをWordPressの `wp-content/plugins/` に配置する
3. WordPress管理画面の「プラグイン」から「WordPress PostText Export」を有効化する
4. 「ツール」→「PostText Export」メニューからアクセスできます

### PDF出力を使う場合

PDF出力で日本語を正しく表示するには、TCPDFライブラリが必要です。

1. [TCPDF](https://github.com/tecnickcom/TCPDF) をダウンロード
2. `lib/tcpdf/` ディレクトリに配置（`lib/tcpdf/tcpdf.php` が存在する状態にする）
3. TCPDFが未導入の場合でもPDF出力は可能ですが、ASCII文字のみの簡易版となります

## 使い方

1. WordPress管理画面で「ツール」→「PostText Export」を開く
2. **対象選択**: エクスポートしたい投稿タイプ、ステータス、期間を選択
3. **「対象件数を確認」ボタン**: 条件に一致する投稿数を事前に確認可能
4. **出力項目**: タイトル、公開日、本文など出力したい項目にチェック
5. **本文整形オプション**: 改行や空行の処理方法を調整
6. **記事の区切り設定**: 複数記事間の区切り方法を選択
7. **出力形式**: TXT または PDF を選択
8. **ファイル名**: 空欄なら自動生成、手入力も可能
9. **「エクスポート実行」**: ファイルがダウンロードされます

| タイトル | 投稿タイトル | ON |
| 公開日 | 投稿の公開日時 | ON |
| 更新日 | 最終更新日時 | OFF |
| 投稿者名 | 投稿者の表示名 | OFF |

## 本文整形オプション

- **段落ごとに改行を入れる**: `<p>`タグの区切りで改行
- **段落間に空行を1行入れる**: 段落間に空行を挿入
- **連続する空行を整理する**: 3行以上の連続改行を2行に圧縮
- **見出しの前後に改行を入れる**: `<h1>`〜`<h6>`の前後に改行
- **リスト要素を改行付きで出す**: `<li>`を「・」付きの行に変換
- **不要な空白を正規化する**: 連続する半角スペースを1つに
- **各行の末尾空白を除去する**: 行末の余分なスペースを削除

## 日本語文字化け対策

- TXT出力はUTF-8 BOM付き（`\xEF\xBB\xBF`）で出力
  - WindowsのメモPad、Excel等でも文字化けしにくい
- HTMLエンティティは `html_entity_decode()` でUTF-8としてデコード
- `&nbsp;` 等の特殊空白はスペースに正規化
- 全角スペースや日本語特殊文字はそのまま保持（破壊しない）
- PDF出力はTCPDF使用時にkozgopromediumフォントで日本語対応

## セキュリティ

- nonceチェックによるCSRF防止
- `export` 権限（管理者に付与）のチェック
- 入力値は `sanitize_text_field()`, `sanitize_key()`, `absint()` 等で適切にサニタイズ
- WP_Query APIを使用（直接SQLは使用しない）

## 将来的な拡張ポイント

- **カテゴリ・タグ・タクソノミーフィルタ**: `WPTE_Post_Query` に `tax_query` パラメータ対応済み
- **CSV / JSON出力**: `WPTE_Exporter` に新しいエクスポートメソッドを追加するだけ
- **項目の表示順変更**: フィールド配列の順序を変更可能な設計
- **バッチ処理・ページング**: クエリクラスに `posts_per_page` / `paged` パラメータ対応済み
- **カスタムフィールド対応**: `wpte_custom_field_value` フィルターで拡張可能
- **テンプレート機能**: エクスポートのフォーマットをテンプレートとして保存
- **出力プレビュー**: エクスポート前に内容をプレビュー表示

## PDF機能の制約

- **TCPDF導入時**: 日本語を含む完全なPDF出力が可能
- **TCPDF未導入時**: ASCII文字のみのシンプルなPDF出力（日本語は表示されません）
- TCPDFはLGPLライセンスのため、WordPressプラグイン（GPL）との互換性あり
- TCPDFを同梱するとファイルサイズが大きくなるため、別途導入する設計としています

## WordPress標準環境での注意点

- WordPress 5.0以上、PHP 7.4以上が必要
- `export` 権限を持つユーザー（通常は管理者）のみ使用可能
- 大量の投稿をエクスポートする場合、PHP の `memory_limit` や `max_execution_time` の設定に注意
- マルチサイト環境ではサイトごとに動作します
